💈 Barbearia NK



Site institucional desenvolvido para a Barbearia NK, com o objetivo de aumentar a presença digital, atrair novos clientes e oferecer uma experiência moderna e prática para agendamentos.

https://barbeariank.com.br

🚀 Objetivo

Este projeto foi criado com foco em:

📈 Atrair mais clientes da região
🌐 Colocar a barbearia na internet
📱 Facilitar o contato e agendamento
💎 Transmitir uma imagem profissional e premium
🧰 Tecnologias utilizadas
HTML5
CSS3
JavaScript (Vanilla JS)
Font Awesome
🎯 Funcionalidades
✅ Layout responsivo (mobile first)
✅ Seção de serviços com preços
✅ Botão de agendamento direto
✅ Integração com WhatsApp
✅ Link para Instagram
✅ Localização via Google Maps
✅ Slider de clientes
✅ Animações suaves
✅ Popup de visualização de imagens
📱 Contato rápido
